# Milestone 2: design paper and evidence appendix (design v3)

This folder holds the simulator, the evidence pipeline and the papers as they come out of it. The final submitted papers, after manual editing, are in [`../paper`](../paper).

- `paper/design_paper.tex` / `.pdf`: the design paper as generated by `build.py paper` from `paper_text.py`
- `paper/appendix_short.tex` / `.pdf`: the 12-page evidence appendix as generated (tables A1, A2, ...), cut from the full appendix by `split_appendix.py`
- `paper/supplement.tex` / `.pdf`: its supplement with everything else (tables B1, B2, ...); the two cross-reference each other
- `paper/evidence_appendix.tex` / `.pdf`: the full generated appendix that both are cut from

Both are US Letter with 1-inch margins and no text below 10 pt. Every number in them is read from `results/*.json` or recomputed from the simulator when the papers are built.

## Layout

| Path | What it is |
|---|---|
| `sim/geom.py` | Kepler propagation, moving-receiver light time, solar exclusion, routes, maintenance |
| `sim/transport.py` | The brief's network: FIFO links, hop and endpoint timers, sessions, quotas, loss, incidents. Also alternative A1 (restart notice) |
| `sim/protocol.py` | v3 ledgers (funding, orders, matching, withdrawals, futures), direct service and forwarding rule R9 (option O2 in older notes; on by default). Audits run after every ledger event |
| `sim/scenarios.py` | Client policy and the S1 scenarios (equity, futures, repeat trading) |
| `sim/evidence.py` | Runs S1, E1, E2, S3, E5, the S2 search and S2 detail. Writes `results/*.json` |
| `sim/e4_scan.py` | 200-year scan of every link, direct path and route, with 1 ms boundary refinement |
| `sim/e4_certify.py` | Interval (Lipschitz) certification of the scan: every open/closed change located, adjacent uncertified leaves merged into intervals (longest 0.29 s), so no period longer than that is missed |
| `sim/e4_bound.py` | Analytic all-time bound on every one-way route delay, checked against the scan |
| `sim/r9_detail.py` | R9 forwarding during the Mars conjunction and at every E5 epoch: per-leg copies, probabilities, forwarder quota |
| `sim/backlog.py` | Backlog after an outage: time to credit and to resolve queues of transfers, quota use, the 512-transfer window (Appendix E6) |
| `sim/e2_full.py` | E2 for every S1 run: every direct message, every backbone launch with per-launch loss and abandonment probability, Monte Carlo for S1f, S1g and S1i (Appendix E2+) |
| `sim/products.py` | Every product (Ares, Belt, Terra, futures) with the client at every settlement, 300 lossy runs each (Appendix S3) |
| `sim/hop_bound.py` | Exact backbone hop-abandonment probability (each retry at its own geometry) and a certified bound allowing 24 h retry delays, with link-open certification (Appendix E2) |
| `sim/saturation.py` | Synthetic ledger-capacity tests at Mars (not compliant network scenarios): slot reservation for payouts and deliveries against the earlier admission rule, and 2,400 late top-ups returned through free slots only (Appendix E6) |
| `sim/md_test.py` | Market data (R5): wait, quote age and cost of quote requests from every exchange for every stock over 30 lossy days, at daily and 6-hourly demand (Appendix E7) |
| `sim/export_traces.py` | Full machine-readable traces (every packet, courier event and ledger event) into `traces/`, for every S1 run, the S3 relocations and the S2 incident |
| `sim/extras.py`, `sim/neptune_futures.py`, `sim/placement.py` | Supporting tables |
| `sim/traces.py` | Seven-column traces generated from the event stream |
| `sim/figs.py` | Figures, drawn at print size |
| `paper/build.py`, `paper/paper_text.py`, `paper/appendix_text.py` | Write both papers as LaTeX from the results and compile them with `pdflatex` |
| `paper/split_appendix.py` | Split `evidence_appendix.tex` into `appendix_short.tex` and `supplement.tex` and compile both (refuses to overwrite a hand-edited `appendix_short.tex` without `--force`) |
| `paper/supp_text.py` | The longer appendix sections: message formats (F), complete traces (T), E2+, E3+, products by settlement, E5 legs, quota/backlog/storage (E6) |
| `paper/html_v1/` | The earlier HTML version of the papers (archived) |

## Reproduce

Requires Python 3.11+ with `numpy`, `matplotlib` and `pillow`, plus a base TeX Live install (`texlive-latex-base`, which provides `pdflatex`) for the PDF step. No extra LaTeX packages are needed. The scripts read `../info/data.zip`, the hackathon's data file.

```bash
cd milestone2/sim
python evidence.py s1 e1 e2 s3 e5 s2search
python -c "from evidence import run_s2_detail; run_s2_detail('reset', 'Mars', 0.75)"
python e4_scan.py
python e4_certify.py
python e4_bound.py
python extras.py
python neptune_futures.py
python r9_detail.py
python export_traces.py
python backlog.py
python e2_full.py
python products.py
python saturation.py
python md_test.py
python figs.py swimlane futures map cdf s2
cd ../paper
python build.py
python split_appendix.py
```

The evidence runs use a 20-process pool. On 20 cores the S2 search takes a few minutes and E4 takes about 43 minutes.
